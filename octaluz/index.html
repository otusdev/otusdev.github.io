Como jogar

  • Arraste as peças da bandeja para o tabuleiro.
  • Complete uma linha ou uma coluna inteira para limpá-la. Várias de uma vez valem mais.
  • Continue limpando nas jogadas seguintes para subir o combo e multiplicar os pontos.
  • Uma peça não cabe agora? Guarde-a no quadrado de guardar e use depois.
  • Aperto no tabuleiro? Use os boosters: martelo, bomba, girar e desfazer.
  • Limpe o tabuleiro inteiro para ganhar um bônus.
  • A partida acaba quando nenhuma peça cabe mais no tabuleiro.

Luz do Dia

Todo dia tem um desafio novo, o mesmo para todo mundo. Bata a meta para acender a luz e ganhe um “continuar” grátis. Dias seguidos formam a sequência, que dá boosters e protetores para os dias em que você não puder jogar. Os troféus do calendário liberam temas novos para o tabuleiro. Depois, compartilhe o resultado e desafie os amigos.
